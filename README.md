# zarishcode — one-line installer

Install [zarishcode](https://www.npmjs.com/package/zarishcode) (a friendly build of
OpenCode) with one command:

```sh
curl -fsSL https://raw.githubusercontent.com/hpmbgd/zarishcode-dist/main/install.sh | bash
```

or, with Node.js:

```sh
npm install -g zarishcode && zarishcode-setup
```

If OpenCode isn't installed yet, the installer installs it for you automatically.

Full step-by-step guide (no coding needed): [GETTING-STARTED.md](./GETTING-STARTED.md).

This public repository holds only the installer and the pack release asset. The
private fork source is never published here.
